# MimoDesk

Serverless P2P remote desktop for Windows (Tauri + Iroh).

## Download

Grab the latest Windows build from **[Releases](https://github.com/mesutde/mimodesk/releases)**.

| Asset | What it is |
|-------|------------|
| `mimodesk.exe` | Portable app — run directly, no install |
| `MimoDesk_0.2.0_x64-setup.exe` | NSIS installer |
| `MimoDesk_0.2.0_x64_en-US.msi` | MSI installer |

## Notes

- Both host and client should run the same version.
- Multi-monitor: pick **Monitör 1 / Monitör 2** in the remote window toolbar.
- Built from the peerdesk / MimoDesk source tree (v0.2.0).
